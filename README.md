## ✨ Features

### 🌌 Interactive 3D Elements

The portfolio uses **Three.js** through **React Three Fiber** and **Drei** for interactive visual elements.

The project includes dedicated 3D components for:

* Hero scene
* Interactive shapes
* Particle effects

### 🎬 Motion & Animations

**Framer Motion** is used for interface animations and transitions, including:

* Section entrance animations
* Navigation animations
* Hover interactions
* Project interactions
* Modal transitions
* UI micro-interactions

### 🖱️ Custom Cursor

A custom cursor component provides an additional interactive element for the desktop experience.

### 📱 Responsive UI

The interface is built to adapt to different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

### 🧩 Reusable React Components

The application is organized into reusable components for major sections and UI elements.

### 🗂️ Interactive Projects

Projects are displayed through reusable project cards, with additional project information available through project modals.

### 🎨 Tailwind CSS

Tailwind CSS is used for the application's styling, layout, responsive behavior, spacing, and visual design.

# 💻 Getting Started

## Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

---

## 1. Clone the Repository

```bash
git clone https://github.com/samu22112005/Portfolio.git
```

Navigate into the project:

```bash
cd Portfolio
```

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Start the Development Server

```bash
npm run dev
```

Vite will start the development server.

Open the local URL shown in the terminal, normally:

```text
http://localhost:5173
```

---

## 4. Run Type Checking

```bash
npm run lint
```

The project's `lint` script runs TypeScript without emitting build files.

---

## 5. Create a Production Build

```bash
npm run build
```

The build command runs TypeScript checking and then creates the Vite production build.

---

## 6. Preview the Production Build

```bash
npm run preview
```

---

# 🌐 Deployment

This is a **Vite frontend application**, so the generated production files can be deployed to a static hosting platform.

The portfolio is currently presented through:

**Live Portfolio:**
https://samrudhi-khopade.hatchable.site

For a standard Vite deployment, build the project with:

```bash
npm run build
```

The generated production output is placed in:

```text
dist/
```

That `dist` directory can then be deployed to a compatible static hosting provider.

> **Note:** `dist/` is a generated build directory and should not be committed to the repository. It is already included in `.gitignore`.

# 🔧 Development Notes

The project uses a clean separation between **content/data** and **UI components**.

For example:

```text
src/data/PortfolioData.ts
```

contains portfolio information, while:

```text
src/components/
```

contains the UI implementation.

The 3D-specific functionality is separated into:

```text
src/components/3d/
```

This includes:

```text
HeroScene.tsx
InteractiveShape.tsx
ParticleField.tsx
```

This structure makes it easier to extend the portfolio with additional visual experiments without tightly coupling the content with the UI.
